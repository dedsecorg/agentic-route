# Commands

| Command | Description |
|---------|-------------|
| `agentic-route status` | Show rules, routes, drift |
| `agentic-route reconcile` | One-shot reconciliation |
| `agentic-route daemon` | Run event-driven daemon |
| `agentic-route intent get` | Show current intent |
| `agentic-route intent set <file>` | Update intent file |
| `agentic-route mcp` | Start stdio MCP server |
